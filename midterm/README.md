FitTrack — Workout Catalog

FitTrack is a responsive workout catalog application built with React. It helps users explore workouts, search for exercises, filter and sort results, view workout details, and add custom workouts.

The project demonstrates React component architecture, state management, asynchronous data loading, controlled forms, and browser-based data persistence.

Features

* Workout Catalog: Browse 120 initial workout records.
* Workout Details: View detailed information about individual workouts.
* Search: Search workouts by name, target muscles, and category.
* Filtering: Filter workouts by category and difficulty.
* Sorting: Sort workouts by name, duration, and calories.
* Pagination: Navigate through workout results.
* Add Workouts: Add custom workouts using a controlled form with input validation.
* Statistics Dashboard: View the total number of workouts, categories, and workout minutes.
* Data Persistence: Save workout data in the browser using localStorage.
* Responsive Design: Use the application on desktop and mobile devices.
* Asynchronous Data Loading: Simulate API requests using Promises and delays.

Data Source

FitTrack uses a simulated asynchronous API implemented in src/api/workoutApi.js.

The API provides functions to retrieve all workouts, retrieve a workout by its ID, and add a new workout.

The initial dataset is generated by src/data/workouts.js and contains 120 workout records.

The simulated API uses Promises, artificial delays, JSON serialization, and localStorage to imitate asynchronous API behavior.

Workout changes are stored in the current browser’s local storage. The application does not use a shared remote database, so saved data is local to each browser.

Getting Started

Prerequisites

* Node.js
* npm

Installation

Clone the repository:

git clone https://github.com/nuralliyevv/React.git

Navigate to the project directory:

cd React/midterm

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL displayed in the terminal.

Available Scripts

Command	Description
npm run dev	Start the development server
npm run build	Build the application for production
npm run preview	Preview the production build locally

Production Build

Create a production build:

npm run build

Vite generates the production files in the dist directory.

Deployment

The application is deployed using GitHub Pages.
