1. Variables and Data Types

Questions

  • let vs const: let can be reassigned, while const cannot be reassigned.
  • typeof null: returns "object". This is a historical JavaScript behavior.
  • Primitive types: string, number, bigint, boolean, undefined, null, symbol.

My insight: I learned that JavaScript has different data types and that variables can store different kinds of values. I also noticed that typeof null returning "object" is a little confusing.

2. Arrays

Original array: [3, 7, 2, 10, 5]

My insight: I learned how map, filter, find, reduce, and includes can make working with arrays easier. I also noticed that these methods allow me to create results without changing the original array.

3. Arrays of Objects

My insight: I learned how to work with arrays that contain objects. Methods like filter, find, and map are useful for searching and transforming student data.

4. Objects

My insight: I learned different ways to work with objects, including changing, adding, and deleting properties. Destructuring also makes it easier to get values from objects.

5. Values and References

My insight: I learned that objects are copied by reference. This means that changing a copied object can also change the original. The spread operator helps create a new object, but nested objects need extra copying.

6. Functions

My insight: I learned how to create functions using both normal syntax and arrow functions. Functions help keep the code organized and allow me to reuse the same logic.

7. Functions as Values

My insight: I learned that functions can be stored in variables and passed to other functions. This was interesting because functions can be used like other values in JavaScript.

8. Scope

My insight: I learned that variables can have different scopes. let and const are block-scoped, while var is function-scoped. I think using let and const makes the code easier to control.

9. Closure

My insight: I learned that an inner function can remember variables from its outer function. The counter example helped me understand how each counter can keep its own value.

10. Destructuring, Spread and Rest

My insight: I learned that destructuring makes it easier to get values from arrays and objects. The spread operator is useful for copying and combining data, while rest collects multiple values.

11. Optional Chaining and Default Values

My insight: I learned that optional chaining helps avoid errors when a property does not exist. I also noticed that ?? is different from || because it only treats null and undefined as missing values.

Final Task

My insight: This task helped me combine the JavaScript concepts from all the previous sections. I used functions, array methods, destructuring, and spread while trying not to modify the original data. I think these concepts will be useful when I start working with React.
